Pesos – acrescentar lojas nos XML do CAWA

Lê a ficha Excel (sheets CNT / CBD / MDL) e acrescenta nos XML MFT_NCR_FTPPUBLICO_SCOT_EANS_* as lojas que ainda não existem.

1. Carregar ficheiros

Os ficheiros são processados só neste browser – nada é enviado para nenhum servidor.

2. Resultado

Como usar
  1. Acrescente as lojas novas no Excel, na sheet da insígnia (colunas APPL | JOB NAME | PARAMETROS).
  2. Carregue aqui o Excel e os XML atuais.
  3. Reveja as lojas a acrescentar e descarregue os XML alterados (mantêm o mesmo nome).
  4. Guarde o original, substitua-o pelo novo e importe no CAWA.
